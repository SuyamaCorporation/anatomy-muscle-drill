# 15 - 筋肉解剖学暗記ドリル

**ビルド日**: 2026-11-03
**カテゴリ**: fun
**slug**: anatomy-muscle-drill

## 概要
人体の主要筋肉26部位をフラッシュカードと4択クイズで学習できるSPA。筋肉名・英名・機能・拮抗筋を収録し、習熟ステータス（新規/学習中/習得済み）を追跡。

## 機能
- 26筋肉データ内蔵（日本語名・英語名・機能・拮抗筋・部位）
- フラッシュカードモード: 筋肉名→クリックで英名・機能・拮抗筋を確認
- 部位フィルター: 上半身・下半身・体幹・全部位
- 習熟ステータスボタン（新規/学習中/習得済み）でカード単位の進捗管理
- クイズモード: 機能の説明から正しい筋肉名を4択で選択
- 一覧タブ: 全筋肉の習熟ステータス・機能・拮抗筋を一覧表示
- 新規/学習中/習得済みのカウント表示
- localStorage習熟ステータス保存
- 進捗リセットボタン
